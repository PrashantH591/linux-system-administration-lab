# 🐧 Linux System Administration Lab

A practical system administration project demonstrating Linux/Unix command-line administration, troubleshooting, security and automation.

This project documents hands-on system administration exercises performed in a controlled personal environment.

---

## 🎯 Objectives

- Manage users and groups
- Understand file permissions
- Monitor system processes
- Investigate disk and storage usage
- Troubleshoot networking
- Inspect running services
- Analyse system information
- Perform basic security checks
- Automate repetitive tasks using Bash

---

## 🔍 Troubleshooting Methodology

1. Identify the problem
2. Gather system information
3. Check logs and system status
4. Test possible causes
5. Apply a controlled change
6. Verify the result
7. Document the solution
